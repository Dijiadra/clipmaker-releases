Politique de confidentialité — ClipMaker

Dernière mise à jour : 31 août 2026

ClipMaker est une application de bureau (Windows) qui transforme des vidéos longues en clips courts pour les réseaux sociaux. Cette page explique quelles données sont traitées, où elles vont, et ce qui reste sur ton ordinateur.

1. Traitement vidéo — 100% local

Le téléchargement de la vidéo source, la transcription audio, le découpage, l'incrustation des sous-titres et toutes les fonctions d'édition (vitesse, filtres, zoom, miroir, filigrane, audio) s'exécutent entièrement sur ton ordinateur. Aucun fichier vidéo n'est envoyé à un serveur ClipMaker — il n'en existe pas.

2. Détection des moments forts — API Gemini (Google)

Pour repérer automatiquement les meilleurs passages, ClipMaker envoie le texte de la transcription (jamais le fichier vidéo) à l'API Gemini de Google, en utilisant la clé API que tu renseignes toi-même dans les paramètres de l'application. Ce traitement est soumis à la politique de confidentialité de Google. ClipMaker ne conserve aucune copie de ce texte après l'analyse.

3. Licence et activation — hors ligne

L'activation premium repose sur une clé de licence signée cryptographiquement (Ed25519), vérifiée localement sur ton appareil. Aucune connexion réseau n'est nécessaire ni effectuée pour valider une licence.

4. Vérification de mise à jour

Au démarrage, l'application interroge l'API publique de GitHub pour connaître la dernière version disponible (aucune donnée personnelle transmise, seule la version actuelle est comparée).

5. Publication sur TikTok (fonctionnalité optionnelle)

Si tu connectes ton compte TikTok, ClipMaker utilise l'API officielle TikTok (Content Posting API) pour publier, à ta demande explicite, un clip généré localement vers ton propre compte TikTok. La connexion se fait via le processus d'autorisation officiel de TikTok (OAuth) : ClipMaker ne voit jamais ton mot de passe TikTok. Le jeton d'accès obtenu est stocké uniquement sur ton appareil et sert exclusivement à publier les vidéos que tu choisis d'envoyer. Aucune donnée de ton compte TikTok n'est transmise à un tiers ni stockée par nous.

6. Achat premium — Telegram

L'achat d'une licence premium se fait via un bot Telegram indépendant. Les informations échangées (preuve de paiement, identifiant Telegram) servent uniquement à générer et transmettre ta clé de licence.
